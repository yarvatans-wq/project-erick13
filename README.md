# Erick Coffee Project ☕

پروژه فروشگاهی قهوه اریک با استفاده از Tailwind CSS و Swiper.

## 🛠 تکنولوژی‌ها
- Vite
- Tailwind CSS v4
- DaisyUI
- Swiper

## 🚀 نصب و اجرا

```bash
# نصب پکیج‌ها
npm install

# اجرا در حالت توسعه
npm run dev

# ساخت نسخه production
npm run build

# پیش‌نمایش build
npm run preview# project-erick13
